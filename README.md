## Poco
A Collaborative Musical Ensemble


## About the Project

Poco is a web application that lets users create music together using devices they already own. Participants join a shared room, choose an instrument, and play through a host computer’s speakers. Started at HackPrinceton, the project aims to lower the equipment barrier to exploring music.

## Project Goals

- Make collaborative music-making more approachable and affordable.
- Allow users to play together from their phones or computers.
- Support beginners with guided notes, sheet music, and shared timing cues.
- Help users create original music through AI-generated arrangements.
- Provide a responsive experience across desktop and mobile devices.

## Core Features

- Real-time multiplayer rooms with room-code access
- Six sampled instruments: piano, violin, flute, trumpet, cello, and xylophone
- Multitouch controls, held notes, and octave switching
- Instrument-specific sheet music and a moving playhead
- Guided performances with highlighted notes and a shared beat indicator
- AI-generated ensemble arrangements based on a mood and selected instruments
- Searchable starter song collection and optional MIDI import

## Technology Stack

- **Languages:** JavaScript, HTML, CSS
- **Frontend:** React, Vite
- **Backend:** Node.js, Express
- **Real-time communication:** Socket.IO
- **Audio:** Tone.js, Web Audio API
- **Sheet music:** VexFlow
- **AI:** Google Gemini API
- **MIDI parsing:** @tonejs/midi
- **Development tools:** Git, GitHub
